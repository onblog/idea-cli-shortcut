# Privacy Policy

**CLI Shortcut for IntelliJ IDEA**

Last updated: June 30, 2026

## Overview

CLI Shortcut is a local-only IntelliJ IDEA plugin that helps developers run command-line scripts from the IDE toolbar. This plugin does not collect, transmit, or store any personal data.

## Data Collection

This plugin does **not** collect any of the following:

- Personal information
- Usage statistics
- Analytics data
- Crash reports
- Telemetry data

## Network Activity

This plugin does **not** make any network connections. All operations are performed locally within your IDE and terminal.

## Data Storage

This plugin stores only:

- Your configured script settings (script names, commands, enabled/disabled state)
- Settings are stored locally in IntelliJ IDEA's standard configuration directory

No data is sent to external servers or third parties.

## Permissions

This plugin requires access to:

- IntelliJ IDEA Terminal: to execute your configured scripts
- Plugin settings: to save your script configurations

These permissions are used solely for the plugin's core functionality.

## Third-Party Services

This plugin does not integrate with any third-party services, APIs, or analytics platforms.

## Changes to This Policy

If this privacy policy is updated, changes will be reflected in the plugin's repository with an updated date.

## Contact

If you have questions about this privacy policy, please open an issue on the [GitHub repository](https://github.com/onblog/idea-cli-shortcut).
